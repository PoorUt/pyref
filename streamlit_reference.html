State Management
4 functions + session_state
Key concept: Streamlit re-runs the entire script on every interaction. st.session_state is the primary mechanism to persist values across reruns.
st.session_statestate
Dict-like object — access via attribute or key
Persists data across reruns for a single browser session. Read: st.session_state.count or st.session_state['count']. Write: same syntax. All widgets with a key are auto-registered here.
st.rerun()state
(no args)
Immediately re-executes the script from the top. Useful after mutating session state or to close dialogs.
st.stop()state
(no args)
Stops script execution at the current point. Everything above is rendered; nothing below is run. Like a return for the whole script.
st.fragment()state
func=None, *, run_every=None
Decorator to mark a function as an isolated fragment — only reruns that function (not the full app) on interaction. Use run_every for polling.
st.query_paramsstate
Dict-like object
Read and write URL query parameters. Changes update the browser URL instantly without a full rerun.

Performance & Caching
4 decorators
When to use which: @st.cache_data for data (DataFrames, CSVs, API calls). @st.cache_resource for shared objects (ML models, DB connections). Both skip re-execution unless inputs change.
@st.cache_datacache
ttl=None, max_entries=None, show_spinner=True, persist=False, hash_funcs=None, experimental_allow_widgets=False
Caches the return value of a function — serialised per user session. Ideal for: loading CSVs, querying APIs, processing DataFrames.
@st.cache_resourcecache
ttl=None, max_entries=None, show_spinner=True, validate=None, hash_funcs=None, experimental_allow_widgets=False
Caches a shared resource — one instance per app (not per user). Ideal for: ML models, DB connection pools, expensive singletons.
.clear()cache
Called on cached function: my_fn.clear()
Clears all cached entries for that function. Also: st.cache_data.clear() / st.cache_resource.clear() to wipe all caches globally.
@st.cache (deprecated)cache
Legacy decorator — deprecated since 1.18
Old all-in-one cache. Replaced by @st.cache_data and @st.cache_resource. Still works but shows a deprecation warning.
