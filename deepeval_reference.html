LLM Output Metrics
Evaluate correctness, relevancy, and tool use
AnswerRelevancyMetric
(threshold=0.5, model=None, include_reason=True, strict_mode=False, verbose_mode=False)
Measures whether actual_output is relevant to input. Uses LLM to judge relevance. Required fields: INPUT, ACTUAL_OUTPUT.
llm-based
CorrectnessMetric
(threshold=0.5, model=None, include_reason=True, strict_mode=False)
Compares actual_output against expected_output for factual correctness. Required: ACTUAL_OUTPUT, EXPECTED_OUTPUT.
llm-based
HallucinationMetric
(threshold=0.5, model=None, include_reason=True, strict_mode=False)
Detects factual claims in actual_output that contradict context. Required: ACTUAL_OUTPUT, CONTEXT.
llm-based
SummarizationMetric
(threshold=0.5, model=None, assessment_questions=None, n=5, include_reason=True)
Evaluates summary quality — coverage + factual consistency. input = source text, actual_output = summary. n = number of QA pairs generated.
llm-based
PromptAlignmentMetric
(prompt_instructions, threshold=0.5, model=None, include_reason=True)
Checks whether actual_output follows each instruction in prompt_instructions (list of strings).
llm-based
JsonCorrectnessMetric
(expected_schema, threshold=1.0, include_reason=False)
Validates actual_output is valid JSON matching a Pydantic model schema. expected_schema is a Pydantic BaseModel class.
non-llmpydantic
ToolCorrectnessMetric
(threshold=1.0, include_reason=False, strict_mode=False)
Checks if tools_called matches expected_tools. Required: TOOLS_CALLED, EXPECTED_TOOLS.
agentnon-llm
TaskCompletionMetric
(threshold=0.5, model=None, include_reason=True, strict_mode=False)
Judges whether an agentic LLM completed the task described in input based on actual_output and tools_called.
agentllm-based
Common metric attributes & methods
metric.measure
(test_case, _show_indicator=True)
Runs the metric on a single test case. Populates .score, .reason, .success.
metric.a_measure
(test_case)
Async version of measure(). Use with await inside async functions.
async
metric.score
→ float (0.0 – 1.0)
Score after calling measure(). Compared against threshold to determine success.
metric.reason
→ str
LLM-generated explanation of the score. Set include_reason=True in constructor.
metric.success
→ bool
True if score >= threshold (or <= for inverted metrics).
metric.strict_mode
→ bool
When True, threshold is forced to 1.0 — any imperfection fails the test.

RAG Metrics
Evaluate retrieval quality and generation faithfulness
RAG Triad — the three core RAG metrics
FaithfulnessMetric
(threshold=0.5, model=None, include_reason=True, strict_mode=False)
Are all claims in actual_output grounded in retrieval_context? High score = no hallucination vs retrieved docs. Required: ACTUAL_OUTPUT, RETRIEVAL_CONTEXT.
llm-basedrag triad
ContextualPrecisionMetric
(threshold=0.5, model=None, include_reason=True, strict_mode=False)
Are relevant nodes ranked higher than irrelevant ones in retrieval_context? Measures retriever ranking quality. Required: INPUT, EXPECTED_OUTPUT, RETRIEVAL_CONTEXT.
llm-basedrag triad
ContextualRecallMetric
(threshold=0.5, model=None, include_reason=True, strict_mode=False)
Is all information in expected_output covered by retrieval_context? Measures retriever coverage/completeness. Required: EXPECTED_OUTPUT, RETRIEVAL_CONTEXT.
llm-basedrag triad
Additional RAG Metrics
ContextualRelevancyMetric
(threshold=0.5, model=None, include_reason=True, strict_mode=False)
Is the retrieval_context relevant to the input? Measures retriever precision (topic alignment). Required: INPUT, RETRIEVAL_CONTEXT.
llm-based
RagasMetric
(threshold=0.5, model=None, embeddings=None)
Wrapper that runs the Ragas evaluation suite (faithfulness, answer relevancy, context precision/recall). Requires ragas package installed.
third-party

(threshold=0.5, model=None, include_reason=True)
Does the chatbot remember facts shared earlier in the conversation? Detects "context amnesia" across turns.
llm-based
ConversationCompletenessMetric
(threshold=0.5, model=None, include_reason=True)
Did the chatbot address all user intentions expressed across the conversation?
llm-based
ConversationRelevancyMetric
(threshold=0.5, model=None, include_reason=True)
Are all chatbot responses relevant to the surrounding conversational context (not just the latest turn)?
llm-based
RoleAdherenceMetric
(threshold=0.5, model=None, include_reason=True)
Does the chatbot consistently stay within its assigned persona/role across the conversation? Pass chatbot_role in ConversationalTestCase.
llm-based

GEval
(name, criteria=None, evaluation_steps=None, evaluation_params, threshold=0.5, model=None, strict_mode=False)
Define any metric with natural language criteria or explicit evaluation_steps. evaluation_params is a list of LLMTestCaseParams specifying which fields to pass to the evaluator LLM.

DAGMetric
(name, dag, model=None, verbose_mode=False)
Directed Acyclic Graph metric. Define a decision tree of criteria nodes. dag is a root TaskNode object. Score flows through the graph.
classadvanced

(threshold=0.5)
Abstract base class for fully custom metrics. Override measure(test_case) and set self.score, self.success, self.reason.
abstract class

TaskNode
(task, children=[])
Evaluates a free-form LLM task/criteria. Root node of a DAG.
dag

(criteria, children_if_true=[], children_if_false=[])
Yes/no binary split. Routes to different sub-graphs based on outcome.
dag
NonBinaryJudgementNode
(criteria, children=[])
Scores 0–1 on a criterion. Continues to children regardless.
dag
VerdictNode
(verdict, score)
Leaf node that assigns a final numeric score.

Synthesizer
Auto-generate goldens and test cases from docs or scratch
Synthesizer
(model=None, embedder=None, multithreading=True, cost_tracking=True, async_mode=True)
Central class for synthetic data generation. Wraps several generation strategies. The model is used for generation; embedder for document chunking/embedding.
class
synthesizer.generate_goldens_from_docs
(document_paths, include_expected_output=True, max_goldens_per_document=5, chunk_size=1024, chunk_overlap=0, num_evolutions=1, evolutions={...}, evolution_limit=None)
Reads document files (PDF, DOCX, TXT), chunks them, and generates question–answer goldens. The most common entry point for RAG evaluation data generation.
rag
synthesizer.generate_goldens_from_contexts
(contexts, include_expected_output=True, max_goldens_per_context=2, num_evolutions=1, evolutions={...})
Generates goldens from pre-chunked context strings you provide. Use when you already have your retrieval chunks.
synthesizer.generate_goldens_from_scratch
(subject, task, output_format, num_initial_goldens=10, num_evolutions=1, evolutions={...})
Generates goldens from a topic description without source documents. Useful for instruction-following, summarisation, or general LLM tasks.
synthesizer.generate_red_teaming_goldens
(purpose, num_goldens=25, attacks=[...], vulnerabilities=[...])
Generates adversarial inputs targeting specific vulnerability categories. Returns goldens without expected_output.
red teaming
synthesizer.save_as
(file_type, directory=".")
Saves generated goldens to "json" or "csv".
Evolution Strategies (used in evolutions= dict)
EvolutionEffect on generated question
Evolution.REASONINGRequires multi-step deduction to answer
Evolution.MULTICONTEXTRequires synthesizing information from multiple chunks
Evolution.CONCRETIZINGMakes abstract questions more concrete/specific
Evolution.CONSTRAINEDAdds constraints or conditions to the question
Evolution.COMPARATIVEAsks to compare two entities from the context
Evolution.HYPOTHETICALPoses a hypothetical/counterfactual scenario

LLM Integration
Use any model as the evaluation judge or inference target
DeepEvalBaseLLM
(abstract base class)
Subclass this to use any custom or local LLM as a judge or benchmark target. Must implement get_model_name(), generate(prompt), and a_generate(prompt).
abstract class
DeepEvalBaseLLM methods to override
get_model_name() → str
get_model_name() returns a display name; generate(prompt, schema=None) returns a string (or Pydantic object if schema passed); a_generate is the async equivalent.
GPTModel
(model="gpt-4o", ...)
Built-in OpenAI wrapper. Default judge model if none specified. Set OPENAI_API_KEY env var.
built-in
DeepEvalBaseEmbeddingModel
(abstract base class)
Subclass for custom embedding models used by the Synthesizer. Must implement embed_text(text) and embed_texts(texts).
abstract class

(target_purpose, target_system_prompt=None, synthesizer_model=None, evaluation_model=None, async_mode=True)
Orchestrates adversarial attack generation + automatic evaluation. target_purpose is a plain-text description of your LLM's function.
class
red_teamer.scan
(target_model, attacks_per_vulnerability=5, vulnerabilities=[...], attack_enhancements={...})
Runs the full red-team scan. Returns RedTeamingResult with vulnerability scores and attack transcripts.
main method

Tracing
Instrument your LLM pipeline for observability on Confident AI
@observe
(*, name=None, type=None, model=None, cost=None, token_usage=None)
Decorator that traces a function call. type is a TraceType enum: LLM, RETRIEVER, TOOL, AGENT, CHAIN, EMBEDDING.
decorator
update_current_span
(*, model=None, input=None, output=None, token_usage=None, cost=None, metadata=None)
Call inside an @observe-decorated function to attach extra metadata to the current trace span at runtime.
TraceType
(enum)
Values: LLM, RETRIEVER, TOOL, AGENT, CHAIN, EMBEDDING, RERANKING. Controls the icon shown in the Confident AI trace viewer.
enum
deepeval.trace_manager
.configure(flush_interval=30, max_queue_size=1000)
Global trace configuration. Set flush interval (seconds) and max buffered spans before flushing to Confident AI.
