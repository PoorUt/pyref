Tensors & Operations
Creation, shaping, indexing, and type casting
Core Types
tf.Tensor
.shape · .dtype · .numpy() · .device
Immutable multi-dimensional array. Key attributes: .shape (TensorShape), .dtype, .numpy() converts to NumPy array.
classimmutable
tf.Variable
(initial_value, trainable=True, name=None, dtype=None)
Mutable tensor. Holds model weights. .assign(v), .assign_add(v), .assign_sub(v) for in-place updates.
classmutabletrainable
tf.TensorSpec
(shape, dtype=tf.float32, name=None)
Describes a tensor's shape and dtype without holding data. Used in tf.function signatures and tf.data.
class
tf.RaggedTensor
.from_row_lengths() / .from_value_rowids()
Tensor with non-uniform row lengths — ideal for variable-length sequences (NLP). Supports most tf ops.
classvariable-length
tf.SparseTensor
(indices, values, dense_shape)
Efficient representation for tensors with mostly zeros. Convert with tf.sparse.to_dense().
classsparse
Creation
tf.constant
(value, dtype=None, shape=None, name='Const')
Creates a constant tensor from a Python value, list, or NumPy array. Result is immutable.
tf.zeros
(shape, dtype=tf.float32, name=None)
Tensor of zeros. tf.zeros_like(x) creates zeros with the same shape and dtype as x.
tf.ones
(shape, dtype=tf.float32, name=None)
Tensor of ones. tf.ones_like(x) variant available.
tf.fill
(dims, value, name=None)
Fills a tensor of shape dims with scalar value.
tf.range
(start, limit=None, delta=1, dtype=None)
1-D tensor of evenly-spaced values. Mirrors Python range().
tf.linspace
(start, stop, num, axis=0, name=None)
Evenly-spaced values over a closed interval [start, stop].
tf.random.normal
(shape, mean=0.0, stddev=1.0, dtype=tf.float32, seed=None)
Random values from a normal distribution. Use tf.random.set_seed(n) for reproducibility.
random
tf.random.uniform
(shape, minval=0, maxval=None, dtype=tf.float32, seed=None)
Random values from a uniform distribution.
random
tf.random.shuffle
(value, seed=None, name=None)
Randomly shuffles a tensor along its first dimension.
random
Shape & Type
tf.reshape
(tensor, shape, name=None)
Returns tensor with new shape. Use -1 to infer one dimension. Data order unchanged.
tf.transpose
(a, perm=None, conjugate=False, name='transpose')
Permutes dimensions. Default reverses all axes. perm=[0,2,1] to swap last two dims.
tf.expand_dims
(input, axis, name=None)
Inserts a new axis of size 1 at axis. Equivalent to x[..., tf.newaxis].
tf.squeeze
(input, axis=None, name=None)
Removes dimensions of size 1. axis to target specific dims.
tf.cast
(x, dtype, name=None)
Casts tensor to a new dtype (e.g. tf.float32 → tf.float16).
tf.shape
(input, out_type=tf.int32, name=None)
Returns the dynamic shape as a 1-D tensor. Use x.shape for static shape.
tf.size
(input, out_type=tf.int32, name=None)
Returns the total number of elements in the tensor.
tf.rank
(input, name=None)
Returns the number of dimensions (rank) as a scalar tensor.
Indexing & Slicing
tf.gather
(params, indices, axis=None, batch_dims=0, name=None)
Gathers slices from params at indices. Like fancy indexing in NumPy.
tf.gather_nd
(params, indices, batch_dims=0, name=None)
Gathers elements using multi-dimensional indices. More powerful than tf.gather.
tf.slice
(input_, begin, size, name=None)
Extracts a sub-tensor starting at begin with given size.
tf.boolean_mask
(tensor, mask, axis=None, name='boolean_mask')
Applies a boolean mask along an axis — selects elements where mask is True.
tf.where
(condition, x=None, y=None, name=None)
Element-wise selection: returns x where condition is True, else y. With one arg, returns indices of True elements.
Combining & Splitting
tf.concat
(values, axis, name='concat')
Concatenates tensors along an existing axis. All dims except axis must match.
tf.stack
(values, axis=0, name='stack')
Stacks tensors along a new axis — increases rank by 1.
tf.unstack
(value, num=None, axis=0, name='unstack')
Unpacks a tensor along an axis into a list of tensors — inverse of tf.stack.
tf.split
(value, num_or_size_splits, axis=0, name='split')
Splits a tensor into sub-tensors. Pass int for equal splits or list for custom sizes.
tf.tile
(input, multiples, name=None)
Tiles a tensor by repeating it multiples times along each dimension.
tf.pad
(tensor, paddings, mode='CONSTANT', constant_values=0)
Pads a tensor. mode: "CONSTANT", "REFLECT", "SYMMETRIC".
tf.repeat
(input, repeats, axis=None, name=None)
Repeats elements of a tensor. Mirrors np.repeat.

Keras — Models
Three ways to build a model
Model APIs
tf.keras.Sequential
([layers])
Simplest API — a linear stack of layers. Add with .add(layer) or pass a list. No branching or multiple inputs/outputs.
beginner
tf.keras.Model
(inputs, outputs, name=None)
Functional API — define a DAG of layers. Pass symbolic tensors to build. Supports multiple inputs/outputs and shared layers.
functional api
class MyModel(tf.keras.Model):
__init__(self) / call(self, inputs, training=False)
Subclassing API — define layers in __init__, forward pass in call(). Most flexible; required for dynamic architectures.
subclassingadvanced
Model methods
model.compile
(optimizer, loss=None, metrics=None, loss_weights=None, run_eagerly=False, steps_per_execution=1, jit_compile=False)
Configures the model for training. Must be called before fit(). Pass string names or objects for optimizer/loss/metrics.
model.fit
(x=None, y=None, batch_size=32, epochs=1, verbose='auto', callbacks=None, validation_split=0.0, validation_data=None, shuffle=True, class_weight=None, sample_weight=None, initial_epoch=0, steps_per_epoch=None)
Trains the model. Returns a History object. x can be NumPy arrays, tf.data.Dataset, or generators.
training
model.evaluate
(x=None, y=None, batch_size=32, verbose='auto', callbacks=None, return_dict=False)
Computes loss and metrics on test data. Returns scalar(s) or dict.
model.predict
(x, batch_size=32, verbose='auto', steps=None, callbacks=None)
Runs inference. Returns NumPy array of predictions. No labels needed.
model.summary
(line_length=None, positions=None, print_fn=None, expand_nested=False, show_trainable=False)
Prints a table of layers, output shapes, and parameter counts.
model.get_weights / set_weights
() / (weights)
Get/set all weights as a list of NumPy arrays. Useful for manual weight transfer.
model.save
(filepath, overwrite=True, save_format=None)
Saves model to SavedModel (default) or HDF5 (.h5) format. Includes architecture, weights, and optimizer state.
serialization
model.trainable_variables
→ list[tf.Variable]
All trainable weight variables. Used with GradientTape for custom training loops.
model.train_on_batch
(x, y, sample_weight=None, return_dict=False)
Runs a single gradient update on one batch of data.

Keras — Layers
All built-in layer types
Core / Dense
layers.Dense
(units, activation=None, use_bias=True, kernel_initializer='glorot_uniform', bias_initializer='zeros', kernel_regularizer=None, ...)
Fully-connected layer: output = activation(input @ kernel + bias).
layers.Activation
(activation, **kwargs)
Applies an activation function as a standalone layer.
layers.Flatten
(data_format=None, **kwargs)
Flattens input to 1-D (keeping batch dim). Commonly used between conv and dense blocks.
layers.Reshape
(target_shape, **kwargs)
Reshapes input to target_shape. Batch dim excluded.
layers.Lambda
(function, output_shape=None, mask=None, arguments=None)
Wraps an arbitrary function as a layer. Not serializable — prefer subclassing for production.
custom
Convolutional
layers.Conv2D
(filters, kernel_size, strides=(1,1), padding='valid', activation=None, use_bias=True, ...)
2D convolution for image data. padding='same' preserves spatial size.
image
layers.Conv1D
(filters, kernel_size, strides=1, padding='valid', activation=None, ...)
1D convolution for sequences/text.
sequence
layers.Conv3D
(filters, kernel_size, strides=(1,1,1), padding='valid', activation=None, ...)
3D convolution for volumetric data (video, 3D scans).
layers.SeparableConv2D
(filters, kernel_size, strides=(1,1), padding='valid', ...)
Depthwise + pointwise convolution. Fewer params than Conv2D — used in MobileNet, Xception.
efficient
layers.Conv2DTranspose
(filters, kernel_size, strides=(1,1), padding='valid', ...)
Transposed convolution (deconvolution) — upsamples spatial dims. Used in decoders and GANs.
upsampling
layers.DepthwiseConv2D
(kernel_size, strides=(1,1), padding='valid', depth_multiplier=1, ...)
Per-channel convolution without mixing channels. First step in separable convolutions.
Pooling
layers.MaxPooling2D
(pool_size=(2,2), strides=None, padding='valid')
Takes the max in each pooling window. Strides defaults to pool_size.
layers.AveragePooling2D
(pool_size=(2,2), strides=None, padding='valid')
Average pooling — smoother than max pooling.
layers.GlobalMaxPooling2D
(data_format=None, keepdims=False)
Reduces spatial dims to 1 value per channel (global max). Outputs shape (batch, filters).
layers.GlobalAveragePooling2D
(data_format=None, keepdims=False)
Global average pooling — used in modern CNNs (ResNet, EfficientNet) instead of Flatten.
layers.MaxPooling1D / AveragePooling1D
(pool_size=2, strides=None, padding='valid')
1D pooling for sequence models.
Recurrent
layers.LSTM
(units, activation='tanh', recurrent_activation='sigmoid', return_sequences=False, return_state=False, stateful=False, dropout=0.0, recurrent_dropout=0.0, ...)
Long Short-Term Memory. Set return_sequences=True for stacked LSTMs.
sequence
layers.GRU
(units, activation='tanh', recurrent_activation='sigmoid', return_sequences=False, return_state=False, stateful=False, dropout=0.0, ...)
Gated Recurrent Unit — fewer params than LSTM, similar performance on many tasks.
sequence
layers.SimpleRNN
(units, activation='tanh', return_sequences=False, return_state=False, stateful=False, dropout=0.0, ...)
Basic RNN cell. Suffers from vanishing gradients — prefer LSTM/GRU in practice.
sequence
layers.Bidirectional
(layer, merge_mode='concat', weights=None)
Wrapper that runs an RNN both forward and backward and merges the outputs.
wrapper
layers.TimeDistributed
(layer, **kwargs)
Applies a layer to every time step independently. Wraps Dense, Conv2D, etc.
wrapper
Attention & Transformers
layers.MultiHeadAttention
(num_heads, key_dim, value_dim=None, dropout=0.0, use_bias=True, ...)
Scaled dot-product multi-head attention. Call as layer(query, value, key, attention_mask).
transformer
layers.Attention
(use_scale=False, score_mode='dot', dropout=0.0)
Single-head attention (Bahdanau/Luong-style). Call as layer([query, value]).
attention
Normalisation & Regularisation
layers.BatchNormalization
(axis=-1, momentum=0.99, epsilon=0.001, center=True, scale=True, ...)
Normalises activations across the batch. Pass training=True in call during training. Behaves differently at train vs inference.
layers.LayerNormalization
(axis=-1, epsilon=0.001, center=True, scale=True, ...)
Normalises across features (not batch). Preferred in Transformers — independent of batch size.
transformer
layers.GroupNormalization
(groups=32, axis=-1, epsilon=0.001, ...)
Normalises within channel groups. Works well with small batch sizes.
layers.Dropout
(rate, noise_shape=None, seed=None)
Sets rate fraction of inputs to 0 during training. Pass training=True in call.
regularization
layers.SpatialDropout2D
(rate, data_format=None)
Drops entire feature maps instead of individual activations — better for correlated spatial data.
regularization
layers.GaussianNoise
(stddev, seed=None)
Adds zero-centred Gaussian noise during training. Regularization for small datasets.
regularization
Embedding & Merging
layers.Embedding
(input_dim, output_dim, embeddings_initializer='uniform', mask_zero=False, ...)
Turns integer indices into dense vectors of output_dim dims. input_dim = vocab size.
nlp
layers.Add / Subtract / Multiply
([tensor_a, tensor_b])
Element-wise merging layers. All inputs must have the same shape.
merge
layers.Concatenate
(axis=-1)
Concatenates a list of tensors along axis.
merge
layers.Dot
(axes, normalize=False)
Computes dot product between two tensors along axes. normalize=True gives cosine similarity.
merge
Upsampling & Preprocessing
layers.UpSampling2D
(size=(2,2), data_format=None, interpolation='nearest')
Repeats rows and columns. interpolation='bilinear' for smoother upsampling.
layers.ZeroPadding2D
(padding=(1,1), data_format=None)
Adds rows/columns of zeros around spatial dimensions.
layers.Rescaling
(scale, offset=0.0, **kwargs)
Rescales inputs: output = input * scale + offset. Use scale=1/255 to normalise images.
preprocessing
layers.Normalization
(axis=-1, mean=None, variance=None)
Normalises features to zero-mean/unit-variance. Call .adapt(data) to compute stats from data.
preprocessing
layers.RandomFlip / RandomRotation / RandomZoom
(mode / factor / ...)
Built-in data augmentation layers. Only active during training. Part of the model — no separate augmentation pipeline needed.
augmentation
layers.TextVectorization
(max_tokens=None, standardize='lower_and_strip_punctuation', split='whitespace', ngrams=None, output_mode='int', output_sequence_length=None, ...)
Maps text strings to integer sequences. Call .adapt(text_data) to build vocab.
nlppreprocessing
Custom Layer Base Class
class MyLayer(tf.keras.layers.Layer):

build() creates weights lazily on first call. call() defines forward pass. get_config() for serialization.
subclassing
self.add_weight
(name, shape, initializer='zeros', trainable=True, regularizer=None, constraint=None)
Creates a trainable or non-trainable weight inside a custom layer's build() method.

Keras — Training
Optimizers, losses, metrics, callbacks, and regularizers
Optimizers
optimizers.Adam
(learning_rate=0.001, beta_1=0.9, beta_2=0.999, epsilon=1e-07, amsgrad=False, ...)
Adaptive Moment Estimation. The default starting optimizer for most tasks.
optimizers.AdamW
(learning_rate=0.001, weight_decay=0.004, beta_1=0.9, beta_2=0.999, ...)
Adam with decoupled weight decay. Preferred for Transformer fine-tuning.
optimizers.SGD
(learning_rate=0.01, momentum=0.0, nesterov=False, ...)
Stochastic Gradient Descent. nesterov=True and momentum=0.9 often outperforms Adam for vision.
optimizers.RMSprop
(learning_rate=0.001, rho=0.9, momentum=0.0, epsilon=1e-07, ...)
Good for RNNs. Maintains a moving average of squared gradients.
optimizers.schedules.ExponentialDecay
(initial_lr, decay_steps, decay_rate, staircase=False)
Decays LR by decay_rate every decay_steps. Pass as learning_rate to optimizer.
lr schedule
optimizers.schedules.CosineDecay
(initial_lr, decay_steps, alpha=0.0, warmup_steps=0, warmup_target=None)
Cosine annealing LR schedule. Standard for large model training.
lr schedule
Loss Functions
losses.SparseCategoricalCrossentropy
(from_logits=False, ignore_class=None, reduction='sum_over_batch_size', name=None)
Multi-class classification with integer labels. Use from_logits=True when your last layer has no softmax.
losses.CategoricalCrossentropy
(from_logits=False, label_smoothing=0.0, ...)
Multi-class classification with one-hot labels. label_smoothing for regularisation.
losses.BinaryCrossentropy
(from_logits=False, label_smoothing=0.0, ...)
Binary or multi-label classification. Output activation: sigmoid (or none + from_logits=True).
losses.MeanSquaredError
(reduction='sum_over_batch_size', name='mean_squared_error')
MSE regression loss.
losses.MeanAbsoluteError
(reduction=..., name='mean_absolute_error')
MAE — more robust to outliers than MSE.
losses.Huber
(delta=1.0, reduction=..., name='huber_loss')
Combines MSE (near zero) and MAE (large errors). Good for regression with outliers.
losses.KLDivergence
(reduction=..., name='kl_divergence')
Kullback-Leibler divergence. Used in VAEs and distribution matching tasks.
losses.CosineSimilarity
(axis=-1, reduction=..., name='cosine_similarity')
Returns negative cosine similarity (for minimisation). Used in contrastive/embedding learning.
Metrics
metrics.Accuracy / SparseCategoricalAccuracy / BinaryAccuracy
(name, dtype)
Classification accuracy variants. Sparse for integer labels, Binary for sigmoid outputs.
metrics.AUC
(num_thresholds=200, curve='ROC', summation_method='interpolation', thresholds=None, multi_label=False, ...)
Area Under the ROC or PR curve. curve='PR' for precision-recall AUC.
metrics.Precision / Recall / F1Score
(thresholds=None, top_k=None, class_id=None)
Classification metrics. F1Score added in Keras 2.12+.
metrics.MeanSquaredError / MeanAbsoluteError
(name, dtype)
Regression metrics tracked across batches.
metrics.Mean
(name='mean', dtype=None)
Tracks mean of arbitrary scalar values. Useful in custom training loops.
Custom metric pattern
class MyMetric(tf.keras.metrics.Metric):
Override update_state(y_true, y_pred, sample_weight), result(), and reset_state().
custom
Callbacks
callbacks.ModelCheckpoint
(filepath, monitor='val_loss', save_best_only=False, save_weights_only=False, mode='auto', save_freq='epoch', ...)
Saves the model at each epoch or at best validation performance.
essential
callbacks.EarlyStopping
(monitor='val_loss', min_delta=0, patience=0, mode='auto', baseline=None, restore_best_weights=False)
Stops training when monitored metric stops improving. restore_best_weights=True reloads the best checkpoint.
essential
callbacks.TensorBoard
(log_dir='logs', histogram_freq=0, write_graph=True, write_images=False, update_freq='epoch', profile_batch=0, embeddings_freq=0, ...)
Logs training metrics for TensorBoard visualisation. Run tensorboard --logdir logs.
callbacks.ReduceLROnPlateau
(monitor='val_loss', factor=0.1, patience=10, mode='auto', min_delta=0.0001, cooldown=0, min_lr=0.0)
Reduces LR by factor when metric plateaus. Essential for cyclic training.
callbacks.LearningRateScheduler
(schedule, verbose=0)
Calls schedule(epoch, current_lr) to compute the new LR each epoch.
callbacks.CSVLogger
(filename, separator=',', append=False)
Streams epoch results to a CSV file.
Custom callback pattern
class MyCallback(tf.keras.callbacks.Callback):
Override hooks: on_epoch_begin/end, on_batch_begin/end, on_train_begin/end. Access self.model.

Regularizers & Initializers
regularizers.L1 / L2 / L1L2
(l=0.01) / (l=0.01) / (l1=0.0, l2=0.01)
Weight regularization penalties added to the loss. Pass to kernel_regularizer in a layer.
initializers.GlorotUniform / HeNormal / Orthogonal
(seed=None)
Weight initializers. Glorot (tanh/sigmoid), He (ReLU). Pass to kernel_initializer.
Activation Functions
activations.relu / leaky_relu / elu / selu
(x, ...)
Rectified activations. leaky_relu allows small negative gradient. selu self-normalises.
activations.sigmoid / tanh / softmax / softplus
(x, axis=-1)
sigmoid: binary output. softmax: multi-class probabilities (sums to 1 along axis).
activations.gelu / swish / mish
(x, approximate=False)
Modern smooth activations. gelu used in BERT/GPT. swish in EfficientNet.

Dataset Creation

Creates a dataset from NumPy arrays or tensors. Slices the first dimension — each element is one sample. Most common for in-memory data.
most common

Wraps a Python generator. Use output_signature with TensorSpec for TF2 style.

(tensors)
Creates a single-element dataset (the whole tensor as one item). Different from from_tensor_slices.
tf.data.TFRecordDataset
(filenames, compression_type='', buffer_size=None, num_parallel_reads=None)
Reads TFRecord files. The standard format for large datasets in TF. Pair with tf.io.parse_single_example.
large scale
tf.data.TextLineDataset
(filenames, compression_type='', buffer_size=None, num_parallel_reads=None)
Creates a dataset by reading lines from text files.
tf.data.Dataset.range
(*args, output_type=tf.int64)
Creates a dataset of integers from a range. Useful for testing pipelines.
Transformations (chainable)
dataset.map
(map_func, num_parallel_calls=None, deterministic=None, name=None)
Applies a function to each element. Set num_parallel_calls=tf.data.AUTOTUNE for speed.
essential
dataset.filter
(predicate, name=None)
Filters elements where predicate(element) returns True.
dataset.batch
(batch_size, drop_remainder=False, num_parallel_calls=None, deterministic=None, name=None)
Batches consecutive elements. drop_remainder=True for fixed batch sizes (required by some models).
essential
dataset.shuffle
(buffer_size, seed=None, reshuffle_each_iteration=True, name=None)
Randomly shuffles using a buffer. Rule of thumb: buffer_size ≥ dataset size for uniform shuffle.
essential
dataset.prefetch
(buffer_size, name=None)
Overlaps data prep and model execution. Always use tf.data.AUTOTUNE at the end of your pipeline.
performance
dataset.cache
(filename='', name=None)
Caches elements in memory (default) or on disk. Speeds up repeated epochs significantly.
performance
dataset.repeat
(count=None, name=None)
Repeats the dataset count times. None repeats indefinitely.
dataset.flat_map / interleave
(map_func, cycle_length=None, block_length=1, num_parallel_calls=None)
flat_map: map + flatten one level. interleave: interleaves outputs (use for reading multiple files in parallel).
dataset.take / skip
(count, name=None)
take(n) returns first n elements. skip(n) skips the first n.
dataset.zip
(datasets, name=None)
Zips multiple datasets together element-wise. Use for (features, labels) pairing.
dataset.padded_batch
(batch_size, padded_shapes=None, padding_values=None, drop_remainder=False)
Batches variable-length sequences by padding. Essential for NLP pipelines.

tf.nn.batch_normalization

numerically stable
tf.nn.l2_normalize

Normalises along axis to unit L2 norm. Used in metric learning.
tf.nn.moments
(x, axes, shift=None, keepdims=False, name=None)
Computes mean and variance of x over given axes. Used in manual batch norm.
tf.nn.ctc_loss / ctc_greedy_decoder
(labels, logits, ...)
Connectionist Temporal Classification — for sequence labelling (speech, OCR) without forced alignment.
sequence

Reductions

(input_tensor, axis=None, keepdims=False, name=None)
